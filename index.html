Publicació a GitHub Pages (https://github.com/ccarras7-cell/prova1)

Quan publiquis la web a GitHub Pages, qualsevol canvi que facis al Google Sheet es veurà reflectit per a tothom automàticament sense necessitat de fer cap `git push` addicional!

  1. Fes push del repositori amb aquests fitxers a ccarras7-cell/prova1.
  2. A GitHub, ves a Settings → Pages.
  3. A Build and deployment, selecciona Source: Deploy from a branch.
  4. Tria la branca main i carpeta / (root) i desa.
  5. En pocs segons, la teva web estarà activa a: https://ccarras7-cell.github.io/prova1/!

Com activar la sincronització de Google Sheets

Perquè la teva pàgina web pugui consultar el document sense que els visitants hagin d'iniciar sessió amb el teu compte de Google, el full de càlcul ha de tenir permisos de lectura pública per a qui tingui l'enllaç:

1

Obre el teu Google Sheet

Fes clic aquí per obrir el document: Obrir Google Sheets ↗

2

Prem el botó blau "Compartir" (Share)

El trobaràs a la cantonada superior dreta de la pantalla de Google Sheets.

3

Canvia a "Qualsevol persona amb l'enllaç"

A l'apartat Accés general, canvia l'opció de Restringit a Qualsevol persona amb l'enllaç i assegura't que el rol a la dreta sigui Lector.

4

Prem "Fet" i torna aquí a sincronitzar

Després de desar, torna a la teva web i prem el botó Sincronitzar Sheets a la barra superior!

💡 Connexió Directa Integrada: L'aplicació incorpora un connector per JSONP que sincronitza tant si visualitzes la web des del navegador en local (arxiu descarregat file://) com si la tens publicada a GitHub Pages, evitant restriccions de CORS.
🔒 Privacitat i Seguretat: En triar el rol Lector, ningú pot modificar les teves dades al full de càlcul; només tu tens permisos d'edició.
